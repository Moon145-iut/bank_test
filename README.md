# ParaBank Selenium Automation Framework

This project is a Java-based UI test automation framework for the ParaBank demo banking
application. It uses Selenium WebDriver, TestNG, Maven, and the Page Object Model to test
realistic banking workflows such as customer login, fund transfers, bill payments, and user
registration.

The framework is designed to keep tests readable and maintainable by separating page
interactions from test logic. It also supports data-driven login testing, positive and
negative scenarios, boundary and security-focused inputs, automated HTML reporting, and
failure screenshots.

This project demonstrates how a QA automation framework can provide reliable regression
coverage while making failures easier to investigate and future locator changes easier to
maintain.
